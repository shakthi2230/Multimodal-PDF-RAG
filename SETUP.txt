MULTIMODAL PDF RAG - SIMPLE SETUP
=================================

Windows PowerShell-la project setup, run, GitHub-ku push panna short guide.

Thevai:
- Git
- Docker Desktop (Docker Compose v2-oda)
- AI features use panna OpenAI API key

1. PROJECT-A CLONE PANNU
-----------------------

PowerShell open panni:

    git clone https://github.com/shakthi2230/Multimodal-PDF-RAG.git
    cd Multimodal-PDF-RAG

Already clone pannirundha latest code edukka:

    git pull origin main

2. .env CONFIGURE PANNU
-----------------------

    Copy-Item .env.example .env
    notepad .env

`.env` file-la:
- `JWT_SECRET`-ku private-a oru long random value podu.
- `OPENAI_API_KEY`-la un OpenAI API key podu.
- Vera settings-a change panna thevai illa.

IMPORTANT: `.env`-a GitHub-ku upload panna koodadhu. API key yaar kittayum
share panna koodadhu.

3. APP-A INSTALL & RUN PANNU
----------------------------

Docker Desktop open-a irukkanum. Project folder-la indha command run pannu:

    docker compose up --build -d

First time konjam neram aagalam; services download/build aagum. Mudinja apram:

    docker compose ps

Browser-la open pannu:
- App: http://localhost:5173
- API docs: http://localhost:8000/docs
- API health: http://localhost:8000/api/health

App-la account register panni, PDF upload panni, processing mudinja apram
question kekkalaam.

Stop panna:

    docker compose down

Thirumba start panna:

    docker compose up -d

4. TEST PANNA
-------------

Backend tests:

    cd backend
    ..\.venv\Scripts\python.exe -m pytest tests -q

Frontend build check:

    cd ..\frontend
    npm ci
    npm run build

Backend tests run panna `.venv` illa-na, project root-la mudhal install pannu:

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
    .\.venv\Scripts\python.exe -m pip install pytest httpx

5. UN CHANGES-A GITHUB-KU PUSH PANNA
------------------------------------

Mudhal changes paaru. `.env`, passwords/API keys, private PDFs stage aagala-nu
check pannu:

    git status
    git diff --check

Upload panna vendiya files mattum stage pannu. Example:

    git add README.md SETUP.txt backend frontend docs docker-compose.yml
    git status

Staged files correct-a irukka check pannitu:

    git diff --cached --stat
    git commit -m "Describe your changes"
    git push origin main

GitHub login ketta, un GitHub account use pannu. Push mudinja verify panna:

    git status --short --branch
    git log -1 --oneline

Original repository-ku push permission illa-na GitHub-la fork create panni,
un fork-ku push pannu. Force push (`git push --force`) use panna vendam.

Problem vandha:
- `docker compose` work aagala-na Docker Desktop install/update panni open pannu.
- AI processing fail aana `.env`-la `OPENAI_API_KEY` correct-a irukka check pannu.
- App open aagala-na `docker compose ps` matrum
  `docker compose logs --tail=100 backend` run panni error paaru.
